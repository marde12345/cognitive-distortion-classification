How this works / important limitations

A predicted category is the model's best guess among the 11 categories it was trained to recognize. Confidence is the model's own estimated probability for that guess — higher is not a guarantee of correctness.

This is an experimental research model, not a clinical, diagnostic, or medically validated tool. A prediction can be wrong, and it must not be treated as a mental-health assessment, diagnosis, or professional judgment about the person who wrote the text.

What is this experiment?

Seven language models were each evaluated on five different splits ("folds") of the same dataset, producing 35 model/fold runs in total. The goal is to compare how these models behave and how consistent each one is across different data splits.

The numbers on this page describe what happened during this experiment. They do not automatically determine which model should be selected for any downstream use — that remains a decision for a person to make, informed by this evidence.

Multi-Seed Experiment (Phase 20)

This is a separate, planned experiment from the Phase 15 sweep and Phase 19 comparison above: the same 7 models on the same 5 folds, each repeated with 3 fixed random seeds (42, 43, 44) — 105 runs in total. It is distinct infrastructure with its own result namespace (results/multiseed/) and never overwrites the Phase 15/16/19 artifacts shown elsewhere on this page.

Methodology & limitations

Each of the 5 folds is evaluated 3 times per model, once per seed, to see how much a model's Macro-F1 varies purely due to random initialization/shuffling rather than the data split. Macro-F1 averages the F1 score of all 11 categories equally, regardless of how common each category is in the data. Anomalous runs (if any occur) are shown explicitly, never silently removed from the official statistics. No automatic model selection, ranking, or "best model" label is computed from this data.

Cross-Fold Stability

A fold is one of several different data splits used to evaluate the model. Looking across folds helps us see whether the observed result changes substantially between splits. Five folds provide useful experimental evidence, but they are still only five observations.

Anomalies

Two runs behaved substantially differently from the other folds of the same model. The available artifacts do not establish the root cause — this is reported as an observation, not a diagnosis.

Per-Class Analysis

Macro-F1 gives each class equal importance when calculating the average. Labels 9 and 10 have relatively low support (few examples), so their per-class values are more sensitive to a small number of predictions — interpret differences involving these two classes cautiously.

Statistical Analysis

Runtime

Runtime tells us how long the training experiments took. It is a different measurement from model quality — a faster or slower run is not evidence of a better or worse model.

Glossary

ModelThe neural network trained to recognize patterns in the text.
FoldOne of several data splits used to evaluate a model.
AccuracyThe percentage of predictions that were correct.
Macro-F1An average performance score where every class receives equal weight.
Weighted-F1An F1 score where classes with more examples have more influence.
Standard deviationA measure of how much a result changes between folds.
AnomalyA result that behaves very differently from the other runs.
Confidence intervalAn estimate of uncertainty around an observed average. With only five folds, this estimate should be interpreted cautiously.
